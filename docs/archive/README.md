# Documentation archive

Everything below this directory is historical and non-normative. It may explain why the product changed, but it must not be used as implementation authority.

The `v0.02/` tree records the previous global `User`, `AgencyMembership`, universal `Party`, Party-role, Office-authorization, and early Departure/Supplier Planning architecture. The active application deliberately rejected those foundations.

For exact repository snapshots, use:

- annotated tag `legacy/v0.02` and branch `archive/party-membership` for the former `main` line;
- annotated tag `archive/phase-3b-supplier-planning` and branch `phase-3b-supplier-planning` for the unmerged Phase 3B work.

Older documents may say **Accepted**, **Current**, or **Authoritative** inside their original text. Their location under this directory overrides those labels: they are archived.

Do not revive an archived record, term, route, permission, or persistence design by copying it. A current ADR and accepted slice plan must explicitly introduce any concept that returns.
